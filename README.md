# صف انتشار اینستاگرام

فقط فایل‌ها را در پوشه‌ی درست آپلود کنید. **اسم فایل = زمان انتشار.**

## پوشه‌ها

| پوشه | پیج |
|---|---|
| `versen.ir/` | versen.ir |
| `daghighnegaar/` | دقیق نگر |
| `kakootilife/` | کاکوتی |
| `faradid.bimeh/` | بیمه فرادید |
| `done/` | فایل‌های منتشرشده (این پوشه را دست نزنید) |

داخل هر پیج سه پوشه هست: `posts/` (پست فید)، `stories/` (استوری)، `reels/` (ریلز).

## قاعده‌ی نام‌گذاری

الگو: `سال-ماه-روز_ساعت‌دقیقه` — تاریخ **شمسی**، ساعت **تهران**، اعداد **انگلیسی**.

| نوع | مثال فایل | کپشن |
|---|---|---|
| پست تکی | `posts/1405-08-10_1830.jpg` | `posts/1405-08-10_1830.txt` |
| کاروسل | پوشه‌ی `posts/1405-08-10_1830/` با `01.jpg`، `02.jpg`، ... (حداکثر ۱۰) | `caption.txt` داخل همان پوشه |
| استوری | `stories/1405-08-10_2100.jpg` یا `.mp4` | ندارد |
| ریلز | `reels/1405-08-10_2000.mp4` | `reels/1405-08-10_2000.txt` |

## قوانین فایل

- عکس فقط **JPG** (نه PNG، نه HEIC).
- ویدیو **MP4**.
- هر فایل حداکثر ۱۰۰ مگابایت.
- استوری: متن، استیکر و هر چیزی که می‌خواهید باید **از قبل روی خود عکس/ویدیو** باشد؛ لینک، نظرسنجی و موزیک از این راه اضافه نمی‌شود.
- کپشن در فایل `.txt` با انکدینگ UTF-8 (پیش‌فرض اکثر ویرایشگرها).
- در اسم فایل فاصله، حروف فارسی یا علامت دیگری نگذارید.
