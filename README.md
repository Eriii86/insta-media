# صف انتشار اینستاگرام

فقط فایل‌ها را در پوشه‌ی درست آپلود کنید. **اسم فایل = روز و ساعت انتشار.**

داخل هر پیج: `posts/` (پست)، `stories/` (استوری)، `reels/` (ریلز).

## نام‌گذاری: فقط ماه و روز، و اگر خواستید ساعت

الگو: `ماه‌روز` یا `ماه‌روز-ساعت‌دقیقه` — تاریخ **شمسی**، ساعت **تهران**، اعداد **انگلیسی**. سال لازم نیست؛ همیشه نزدیک‌ترین همان تاریخ در آینده حساب می‌شود.

| اسم فایل | یعنی |
|---|---|
| `0810.jpg` | ۱۰ آبان، ساعت پیش‌فرض **۲۰:۰۰** |
| `0810-1830.jpg` | ۱۰ آبان، ساعت ۱۸:۳۰ |
| `0810-0900.jpg` | ۱۰ آبان، ساعت ۹ صبح |
| `1203-2100.mp4` | ۳ اسفند، ساعت ۲۱:۰۰ |

چند فایل در یک روز؟ ساعت‌شان را متفاوت بگذارید (`0810-1200`، `0810-2000`).

## کپشن و کاروسل

| نوع | فایل | کپشن |
|---|---|---|
| پست تکی | `posts/0810-1830.jpg` | `posts/0810-1830.txt` |
| کاروسل | پوشه‌ی `posts/0810-1830/` با `01.jpg`، `02.jpg`، ... (حداکثر ۱۰) | `caption.txt` داخل همان پوشه |
| استوری | `stories/0810-2100.jpg` یا `.mp4` | ندارد |
| ریلز | `reels/0810-2000.mp4` | `reels/0810-2000.txt` |

## قوانین فایل

- عکس فقط **JPG** (نه PNG، نه HEIC). ویدیو **MP4**. هر فایل حداکثر ۱۰۰ مگابایت.
- استوری: متن و استیکر باید **از قبل روی خود عکس/ویدیو** باشد.
- کپشن در فایل `.txt` با انکدینگ UTF-8.
- در اسم فایل فاصله، حروف فارسی یا علامت دیگری نگذارید.
